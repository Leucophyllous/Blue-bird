# Bring Back Twitter

X（旧Twitter）を、かつての **Twitter** の見た目に戻す Chrome 拡張機能です。
ロゴを青い鳥に戻し、配色やテキストを以前のものに置き換え、プレミアム勧誘や Grok などの要素を非表示にします。

## 主な機能

- **ロゴを青い鳥に** — X ロゴ・ファビコンを Twitter の青い鳥（#1DA1F2）に置き換え
- **アイコンを旧仕様に** — ホーム / 探索（#）/ DM / コミュニティのナビアイコンを以前のスタイルに
- **テキストを旧表記に** — 「ポスト → ツイート」「リポスト → リツイート」「いまを見つけよう → いまどうしてる？」など
- **タイトル / 検索プレースホルダー** を Twitter 時代の表記に
- **不要な要素を非表示** — プレミアム勧誘バナー・サブスク導線、クリエイタースタジオ、「もっと見る」内のビジネス/広告/コミュニティ項目など

すべて [`content.js`](content.js) のコンテンツスクリプトと [`styles.css`](styles.css) で実現しており、外部通信は行いません。

## 対応サイト

`x.com` および `twitter.com`

## インストール（開発者モード）

1. このリポジトリをダウンロード（またはクローン）します。
   ```bash
   git clone https://github.com/Leucophyllous/Blue-bird.git
   ```
2. Chrome で `chrome://extensions` を開きます。
3. 右上の **デベロッパーモード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、このフォルダを選択します。
5. `x.com` を開くと反映されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `content.js` | ロゴ・アイコン・テキスト置換、不要要素の非表示 |
| `styles.css` | 配色・レイアウトの調整 |
| `icons/` | 拡張機能アイコン（16/32/48/128px） |
